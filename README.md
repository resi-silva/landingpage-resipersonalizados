# Landing Page — Loja de Papelaria Personalizada

Landing page inspirada no site Dani Papeleira, criada com HTML/CSS/JS puro.

## Estrutura

```
landing-page/
├── index.html           # Página principal (completa)
├── styles/
│   ├── reset.css        # Reset/normalize
│   └── style.css        # Estilos completos (mobile-first)
├── scripts/
│   └── main.js          # Menu, slider, interações
├── assets/
│   ├── images/          # Coloque suas imagens aqui
│   └── fonts/           # Coloque fontes locais aqui
└── README.md
```

## Seções

1. **Topbar** — Cupom de desconto + redes sociais
2. **Header** — Logotipo, menu com dropdowns, busca, conta, carrinho
3. **Hero Slider** — Banner rotativo com 3 slides
4. **Serviços** — 4 diferenciais (amor, frete grátis, parcelamento, segurança)
5. **Produtos em Destaque** — Grid de cards com preço e parcelamento
6. **Categoria Banner** — "Festa na Caixa Personalizada"
7. **Mais Produtos** — Grid com badges "NO VO"
8. **WhatsApp CTA** — Seção de contato
9. **Footer** — Links, contato, redes sociais, formas de pagamento
10. **WhatsApp Float** — Botão flutuante do WhatsApp

## Personalização

- **Cores**: edite as variáveis `:root` no `style.css`
- **Logotipo**: substitua "SuaLoja" no `index.html`
- **Telefone WhatsApp**: troque `5511999999999` em 3 locais no HTML
- **Imagens**: substitua os placeholders (emoji) por imagens reais em `assets/images/`
- **Textos**: edite diretamente no `index.html`

## Deploy no GitHub Pages

Veja instruções no README anterior ou apenas abra o `index.html` no navegador.
